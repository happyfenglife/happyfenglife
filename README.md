### `$ whoami`

一句话说清楚**你是谁、你在做什么、你关心什么**。不要写“热爱技术”“持续学习”这类放之四海而皆准的话。

我是一名 **[角色]**，专注于 **[领域/方向]**。目前在做 **[当前项目或工作]**，关注 **[1–2 个真实的技术或产品兴趣]**。

- 🔭 正在构建：**[项目名称]** — 一句话说明它解决什么问题
- 🌱 正在深入：**[技术/领域]**
- 💬 可以聊：**[你真正有积累的话题]**
- 📫 联系：**[email / X / LinkedIn，只放你真正会看的渠道]**

### Featured Projects

不要列出所有仓库。**选 2–3 个你真正想被讨论的项目**，每个项目给出一行问题 + 一行结果[reference:2]。

**🚀 [Project Name](https://github.com/username/project)**  
一句话说明**用户痛点**。用 **[技术栈]** 构建，实现了 **[可量化的结果：性能提升 / 用户量 / star 数 / 被谁使用]**。

**🛠 [Project Name](https://github.com/username/project)**  
一句话说明**为什么做它**。被 **[谁]** 用于 **[什么场景]**，或获得了 **[什么反馈]**。

**📦 [Project Name](https://github.com/username/project)**  
一句话说明**它的独特之处**。如果你没有“硬结果”，就诚实地说清楚它解决了什么具体的小问题。
